**C27** (함정: 1:N 팬아웃, 3회) — 실행 실패: SELECT 실행 실패: (pymysql.err.OperationalError) (1055, "Expression #2 of SELECT list is not in GROUP BY clause and contains nonaggregated column 'csu_db.BUILDING_IP_COUNTS.IP가_부여된_단말기_수' which is not functionally dependent on columns in GROUP BY clause; this is incompatible with sql_mode=only_full_grou
> 호관별로 한 행씩 만들어줘.

```sql
SELECT `호관`, 
       `IP가_부여된_단말기_수` AS `BUILDING_IP_COUNTS_단말기_개수`,
       SUM(`단말기_개수`) AS `ROOM_IP_COUNTS_단말기_개수_합`
FROM `BUILDING_IP_COUNTS`
LEFT JOIN `ROOM_IP_COUNTS`
```

> INFO_SYS에서 서버를 가장 많이 가진 제조사의 서버 모델명을 중복 없이 보여줘

```sql
SELECT `제조사`, `모델명` FROM `INFO_SYS` WHERE `종류` = '서버' GROUP BY `제조사`, `모델명` HAVING COUNT(*) = (SELECT COUNT(*) AS cnt FROM `INFO_SYS` WHERE `종류` = '서버' GROUP BY `제조사`, `모델명` ORDER BY cnt DESC LIMIT 1);
```
