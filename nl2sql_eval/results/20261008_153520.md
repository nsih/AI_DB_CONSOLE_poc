**H06** (날짜 집계, 3회) — 실행 실패: SELECT 실행 실패: (pymysql.err.OperationalError) (1055, "Expression #1 of ORDER BY clause is not in GROUP BY clause and contains nonaggregated column 'csu_db.DORM_AP_EXTENDER.설치_날짜' which is not functionally dependent on columns in GROUP BY clause; this is incompatible with sql_mode=only_full_group_by")
> 기숙사 AP 익스텐더가 월별로 몇 대씩 설치됐는지 보여줘. 설치 날짜가 없는 건 빼고, 월 오름차순으로

```sql
SELECT `호관`, COUNT(*) AS `설치_대수` 
FROM `DORM_AP_EXTENDER` 
WHERE `설치_날짜` IS NOT NULL 
GROUP BY `호관` 
ORDER BY LEFT(`설치_날짜`, 7) ASC;
```

**H08** (함정: NULL 그룹, 3회) — 오답: 정답 1번째 컬럼과 값이 같은 컬럼이 없음
> 익스텐더가 가장 많이 설치된 날짜와 그날 설치된 대수는?

```sql
SELECT 설치_날짜, COUNT(*) AS 설치_대수
FROM DORM_AP_EXTENDER
GROUP BY 설치_날짜
ORDER BY COUNT(*) DESC
LIMIT 1;
```

**H12** (조인: 차집합, 3회) — 오답: 정답 1번째 컬럼과 값이 같은 컬럼이 없음
> INFO_SYS에 IP가 적혀 있는데 그 IP가 IP 테이블에는 없는 장비는 몇 대야?

```sql
SELECT COUNT(*) FROM INFO_SYS 
LEFT JOIN IP ON INFO_SYS.IP_Adress = IP.IP 
WHERE IP.IP IS NULL;
```
