### 재생성 2회 — 실패 22건

**H06** (날짜 집계, 3회) — 오답: 행 수 다름 (정답 5, 생성 6)
> 기숙사 AP 익스텐더가 월별로 몇 대씩 설치됐는지 보여줘. 설치 날짜가 없는 건 빼고, 월 오름차순으로

```sql
SELECT `호관`, YEAR(`설치_날짜`) AS `년`, MONTH(`설치_날짜`) AS `월`, COUNT(*) AS `설치_개수` 
FROM `DORM_AP_EXTENDER` 
WHERE `설치_날짜` IS NOT NULL 
GROUP BY `호관`, YEAR(`설치_날짜`), MONTH(`설치_날짜`) 
ORDER BY YEAR(`설치_날짜`), MONTH(`설치_날짜`);
```

**H08** (함정: NULL 그룹, 3회) — 오답: 정답 1번째 컬럼과 값이 같은 컬럼이 없음
> 익스텐더가 가장 많이 설치된 날짜와 그날 설치된 대수는?

```sql
SELECT `설치_날짜`, COUNT(*) AS `설치된_대수` FROM `DORM_AP_EXTENDER` GROUP BY `설치_날짜` ORDER BY `설치된_대수` DESC LIMIT 1;
```

**H10** (서브쿼리+범주, 3회) — 오답: 행 수 다름 (정답 2, 생성 32)
> 서버 중에서 가장 최근에 도입된 것들의 관리번호, 모델명, 도입년도를 보여줘

```sql
SELECT `관리번호`, `모델명`, `도입년도` FROM `INFO_SYS` WHERE `종류` = '서버' ORDER BY `도입년도` DESC;
```

**H12** (조인: 차집합, 3회) — 오답: 정답 1번째 컬럼과 값이 같은 컬럼이 없음

**H20** (NULL+집계, 3회) — 오답: 행 수 다름 (정답 8, 생성 10)
