**C06** (필터, 3회) — 오답: 정답 1번째 컬럼과 값이 같은 컬럼이 없음
> INFO_SYS에서 2020년 이후(2020년 포함)에 도입된 네트워크장비는 몇 대야?

```sql
SELECT COUNT(*) FROM `INFO_SYS` WHERE `도입년도` >= '2020' AND `종류` = '서버';
```

**C24** (계산식, 3회) — 오답: 정답 2번째 컬럼과 값이 같은 컬럼이 없음
> BUILDING_IP_COUNTS에서 호관별로 호실 하나당 평균 단말기 수를 소수점 둘째 자리까지 구해줘

```sql
SELECT `호관`, ROUND(`호실_수` / `IP가_부여된_단말기_수`, 2) AS `평균_단말기_수`
FROM `BUILDING_IP_COUNTS`;
```

**C27** (함정: 1:N 팬아웃, 3회) — 오답: 행 수 다름 (정답 8, 생성 1)
> 호관별로 한 행씩 만들어줘.

```sql
SELECT `호관`, SUM(`단말기_개수`) AS `호실_단말기_합계`
FROM `BUILDING_IP_COUNTS`
JOIN `ROOM_IP_COUNTS` ON `BUILDING_IP_COUNTS`.`호관` = `ROOM_IP_COUNTS`.`사용호실`
GROUP BY `호관`
ORDER BY `호관`;
```
