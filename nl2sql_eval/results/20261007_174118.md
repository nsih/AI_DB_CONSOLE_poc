**H06** (날짜 집계, 3회) — 오답: 행 수 다름 (정답 5, 생성 6)
> 기숙사 AP 익스텐더가 월별로 몇 대씩 설치됐는지 보여줘. 설치 날짜가 없는 건 빼고, 월 오름차순으로

```sql
SELECT `호관`, YEAR(`설치_날짜`) AS `년`, MONTH(`설치_날짜`) AS `월`, COUNT(*) AS `설치_개수` 
FROM `DORM_AP_EXTENDER` 
WHERE `설치_날짜` IS NOT NULL 
GROUP BY `호관`, YEAR(`설치_날짜`), MONTH(`설치_날짜`) 
ORDER BY YEAR(`설치_날짜`), MONTH(`설치_날짜`);
```

**H08** (함정: NULL 그룹, 3회) — 오답: 정답 1번째 컬럼과 값이 같은 컬럼이 없음

**H12** (조인: 차집합, 2회) — 오답: 정답 1번째 컬럼과 값이 같은 컬럼이 없음

**H25** (서브쿼리+조인, 3회) — 오답: 행 수 다름 (정답 1, 생성 0)
> 단말기가 가장 많은 호실이 속한 호관의 호실 수를 BUILDING_IP_COUNTS에서 찾아줘. 사용호실의 첫 글자가 호관 번호다
