**C18** (HAVING, 2회) — 오답: 정답 2번째 컬럼과 값이 같은 컬럼이 없음
> DORM_AP_EXTENDER에서 설치 날짜가 기록된 장비만 대상으로, 하루에 3대 이상 설치된 날짜와 그 날의 설치 대수를 보여줘

```sql
SELECT `호관`, `설치_날짜`, COUNT(`장비명`) AS `설치_대수`
FROM `DORM_AP_EXTENDER`
WHERE `설치_날짜` IS NOT NULL
GROUP BY `호관`, `설치_날짜`
HAVING `설치_대수` >= 3;
```

**C24** (계산식, 3회) — 오답: 정답 2번째 컬럼과 값이 같은 컬럼이 없음
> BUILDING_IP_COUNTS에서 호관별로 호실 하나당 평균 단말기 수를 소수점 둘째 자리까지 구해줘

```sql

```
